## sync_tabs_and_bookmarks_with_file

Browser extension (Chrome + Firefox, one source tree) that exports bookmarks and open tabs
to files automatically, so a fresh machine can be restored from them.

    cd sync_tabs_and_bookmarks_with_file
    node build.js

Chrome: `chrome://extensions` → Developer mode → Load unpacked → `dist/chrome`.

See [`sync_tabs_and_bookmarks_with_file/README.md`](sync_tabs_and_bookmarks_with_file/README.md)
for Firefox, settings, restore and what is still unverified.
